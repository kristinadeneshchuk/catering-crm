# БУР — прокат будівельного інструменту

Натяжка дизайн-хендофа `design_handoff_bur_rental` на Laravel. Макети з папки
`design/` були прототипами в HTML; тут вони відтворені як застосунок:
Blade + Tailwind v4 + Alpine, дані — в Eloquent, а не в інлайн-масивах.

## Запуск

```bash
composer install
npm install

cp .env.example .env
php artisan key:generate

touch database/database.sqlite
php artisan migrate:fresh --seed     # сид кладе реальний контент з макетів

npm run build     # або npm run dev
php artisan serve
```

Тести: `php artisan test`. Стиль: `./vendor/bin/pint`.

Адмінка — `/admin`. Сид створює два акаунти:

| Пошта | Пароль | Роль |
| --- | --- | --- |
| `admin@bur.local` | `password` | адмін |
| `manager@bur.local` | `password` | менеджер філії «Позняки» |

**Паролі демонстраційні — перед деплоєм змініть їх і не заливайте `StaffSeeder`
на бойовий сервер як є.**

## Адмінка

Filament 5 на `/admin`, українською, в кольорах сайту. Розділи меню:

| Розділ | Що там |
| --- | --- |
| **Замовлення** | Бронювання (з життєвим циклом), Заявки з форм сайту |
| **Каталог** | Товари, Категорії, Бренди, Витратники, Комплекти |
| **Наявність** | Календар зайнятості парку |
| **Географія** | Міста, Філії, Райони, Зони доставки |
| **Контент** | Відгуки, FAQ |

**Інфопанель** відповідає на питання «що робити зараз»: скільки видати й прийняти
сьогодні, що прострочено, скільки броней і заявок необроблено, який відсоток парку
зайнято. Нижче — таблиця сьогоднішніх справ, де видати й прийняти техніку можна
прямо звідти, і виручка за два тижні (без застави — це не дохід).

**Життєвий цикл броні** живе в `App\Services\BookingWorkflow`, а не в кнопках:
нова → підтверджена → видана → закрита (або скасована). Головне правило — зайняті
дати з'являються і зникають разом зі станом броні:

- **Приймання** питає фактичну дату повернення. Здали раніше — перераховуємо за
  фактичним строком і звільняємо невикористані дні. Привезли пізніше — добираємо
  прострочені доби за базовим тарифом, бо знижка за строк на прострочення не діє.
- **Скасування** повертає всі дати в календар: скасована бронь не має тримати
  техніку, яка стоїть на полиці.

**Календар зайнятості** — рядок на модель, стовпчик на день, як у зошиті
менеджера. Клік по вільному дню блокує його на сервіс, клік по сервісному —
знімає. Дні під реальною орендою звідти не звільняються: інструмент фізично в
руках у клієнта, і відпустити його може тільки приймання.

**Ролі.** `admin` бачить усе, `manager` — те саме, але призначений філії
(`users.branch_id`). Звільненому достатньо зняти `is_active`: пароль при ньому
лишиться, а панель більше не пустить.

**Чого в адмінці свідомо немає:** створення броні руками. Бронь, заведена в
обхід сайту, не проходить перевірку наявності — телефонне замовлення менеджер
оформлює через сайт від імені клієнта.

## Наповнення і ринок

Каталог заповнений під київський ринок прокату 2026 року, а не вигаданими
цифрами. Орієнтири, за якими виставлені тарифи (дані з відкритих прайсів
конкурентів — budprokat, samrent, rentnow, pikkampani, rental-power, novarent):

| Позиція | Ринок, ₴/добу | Базовий тариф у нас |
| --- | --- | --- |
| Дрібний ручний інструмент | від 60 | 60–150 |
| Перфоратор SDS-plus | 135–300 | 230–300 |
| Штроборіз | 350–500 | 450 |
| Глибинний вібратор | від 135 | 200 |
| Осушувач повітря | 150–180 | 260 (20 л/добу) |
| Віброплита 90 кг | ~350 | 350 |
| Інверторний генератор 2 кВт | від 315 | 450 |
| Алмазне буріння | від 700 | 850 |

Що з ринку враховано в моделі:

- **Мінімальний строк — 1 доба**, як у всіх. Знижка за строк у конкурентів
  зазвичай «10% від тижня, до 40% за місяць» і згадується текстом; ми
  показуємо її одразу цінами в тарифній сходинці (−17% / −31%).
- **Застава** — за класом техніки, як прийнято в ніші: 400–2 000 ₴ за ручний
  електроінструмент, 2 000–4 000 за бензо- і садову, 4 000–8 000 за віброплити,
  генератори й алмазне буріння.
- **Витратники не входять в оренду.** Бури, диски, коронки, ліска, електроди —
  окремі позиції, які докуповують на видачі. Це стандарт ринку і водночас
  найчастіше джерело непорозумінь, тому написано на кожній картці.
- **Важка техніка від 200 кг самовивозом не видається** — тільки доставка
  гідробортом. Доплати за гідроборт і вагу фіксовані.

Каталог: 48 позицій, 12 категорій, 12 підкатегорій, 21 бренд, 18 витратників,
8 комплектів під задачу, 54 питання в FAQ. Кількість позицій у меню
рахується з бази (`CatalogSeeder::recountCategories`), а не проставляється
руками — цифра в каталозі завжди збігається з тим, що людина побачить
усередині.

## Рішення, які варто знати

**Токени, а не хардкод.** Уся палітра, типографічна шкала, радіуси й брейкпойнти
живуть у `@theme` в `resources/css/app.css`. У розмітці hex-значень немає —
якщо додаєте колір, спершу токен.

**Три радіуси.** `2px` чипси · `6px` кнопки і поля · `12px` картки. `32px` —
тільки pill нижньої навігації. Четвертого радіуса бути не має.

**Тіней немає.** Рівні поверхонь передаються бордером і фоном. Єдиний виняток —
`--shadow-float` для плаваючих шарів: модалка, тост, sticky-панель, bottom nav.

**Дати зберігаються як `Y-m-d`.** `UnavailableDate` має мутатор, який зрізає час.
Без нього Eloquent клав «2026-08-14 00:00:00», `firstOrCreate` не знаходив наявний
рядок, вставляв дубль і падав на унікальному індексі — бронювання на дату, вже
чимось зайняту, віддавало 500. Є тест.

**Наявність — правда, і рахується поштучно.** `unavailable_dates` тримає
зайняті екземпляри по парі товар+філія з посиланням на бронь, `inventory.qty` —
скільки одиниць стоїть на складі. Модель стає недоступною, тільки коли зайнято
всі екземпляри: три перфоратори на Позняках витримують три паралельні броні.
Прив'язка рядка до `booking_id` принципова — без неї дострокова здача однієї
броні знімала б блокування чужої на ті самі дати. Уся логіка в
`App\Services\Availability`, кешувати її агресивно не можна: це головна
перевага сервісу, і вона мусить бути правдивою.

**Ціни рахує сервер.** `App\Services\RentalPricing` бере тариф із бази за
фактичним строком. Ціна, надіслана браузером, ігнорується повністю — тарифну
сходинку в devtools правити легше, ніж здається. Є тест саме на це.

**Тарифна сходинка.** Три рівні на товар у `tariff_tiers`: 1–2 дні базовий,
від 3 днів −17%, від 7 днів −31%. Повзунок днів на PDP одночасно перемикає
активний рівень, зсуває кінцеву дату в календарі та перераховує підсумок —
без кнопки «Розрахувати».

**Місто — наскрізний контекст.** `ResolveCity` резолвить його один раз на запит
із маршруту або сесії й кладе в атрибути. Від нього залежать телефон у хедері,
список філій і зони доставки на всіх сторінках.

**Стан клієнта.** Місто, філія, дати, кошик і список порівняння лежать у
localStorage (`resources/js/stores/booking.js`) і переживають перезавантаження.
Дати з URL мають пріоритет над збереженими — це шаринг посилання.

**Кожна дія — реальний маршрут.** `href="#"` у розмітці немає: кнопка
«Забронювати» в картці лістингу веде на PDP з уже підставленими датами й філією.

## Чого свідомо немає

- **Фото і карти** — плейсхолдери `<x-image-slot>` із зарезервованим
  `aspect-ratio`. Пропорції збережені, щоб при підстановці реальних фото
  сторінка не стрибнула (вимога нульового CLS). Карти — заглушки такої ж висоти.
- **RU-версія** — перемикач у футері передбачений дизайном, але другої мови
  ще немає, тому він неактивний, а не веде в нікуди.
- **Кабінет клієнта й обране** — в хендофі описані тільки як пункти навігації,
  екранів для них немає. Зараз ведуть на існуючі сторінки.
- **Оплата** — спосіб оплати зберігається в брони, платіжний шлюз не
  підключений.
- **Пошук** — поки простий `LIKE` по назві, артикулу й бренду: не пробачає
  одруківок і не знає російських назв. Під нормальний потрібен Scout з
  Meilisearch.

## Шрифти

Зараз Oswald / Golos Text / JetBrains Mono підключені через Google Fonts у
`layouts/app.blade.php`. Для продакшену їх варто self-host'ити: шрифти лежать
у критичному шляху LCP, а сторонній домен додає зайвий handshake. Найпростіше —
плагін шрифтів `laravel-vite-plugin`:

```js
// vite.config.js
import { bunny } from 'laravel-vite-plugin/fonts';

laravel({
    input: ['resources/css/app.css', 'resources/js/app.js'],
    fonts: [
        bunny('Oswald', { weights: [500, 600, 700], subsets: ['cyrillic-ext', 'latin'] }),
        bunny('Golos Text', { weights: [400, 500, 600], subsets: ['cyrillic-ext', 'latin'] }),
        bunny('JetBrains Mono', { weights: [400, 600, 700], subsets: ['cyrillic-ext', 'latin'] }),
    ],
}),
```

після чого прибрати `<link>` на Google Fonts з layout. Обов'язково лишіть
підмножину `cyrillic-ext` — без неї зникнуть і, ї, є, ґ.
