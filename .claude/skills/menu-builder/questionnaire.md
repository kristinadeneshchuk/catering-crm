# Опитувальник клієнта (заповнює менеджер зі слів клієнта)

Мета: зібрати мінімум, достатній для розрахунку КБЖУ, підбору тарифу і генерації
персонального тижневого меню. Питання йдуть блоками — менеджер може відповідати
списком у вільній формі, скіл сам розкладе по полях і перепитає лише те, чого бракує.

## Блок 1 — Хто клієнт (для розрахунку КБЖУ)

1. Стать: чоловік / жінка
2. Вік (років)
3. Зріст (см)
4. Вага (кг)
5. Рівень активності:
   - `мінімальний` — сидяча робота, без спорту (×1.2)
   - `легкий` — тренування 1–3 рази/тиждень (×1.375)
   - `середній` — тренування 3–5 разів/тиждень (×1.55)
   - `високий` — важкі тренування 6–7 разів/тиждень (×1.725)
   - `дуже високий` — фізична робота + спорт (×1.9)
6. Ціль:
   - `схуднення` (дефіцит 15–20%)
   - `підтримка` (без корекції)
   - `набір` (профіцит 10–15%)
   - або клієнт одразу називає бажаний калораж — тоді пункти 1–5 опційні

## Блок 2 — Обмеження по їжі

7. Алергії (перелік; звіряємо зі довідником алергенів CRM)
8. Продукти, які категорично не їсть (нелюбимі/релігійні/етичні обмеження)
9. Тип харчування: звичайне / без лактози / без глютену / вегетаріанство / веган / інше
10. Медичні обмеження, якщо є (діабет, гастрит тощо — фіксуємо як коментар для технолога)

## Блок 3 — Формат раціону

11. Кількість прийомів їжі на день: 3 / 4 / 5 (сніданок, обід, вечеря, перекуси)
12. Що любить найбільше (топ-3 улюблені страви/продукти — щоб «влучити в серце»)
13. Кухня/стиль: без переваг / українська / середземноморська / азійська / ПП-класика
14. Побажання по вуглеводах увечері: без обмежень / мінімум вуглеводів на вечерю

## Блок 4 — Гроші та логістика

15. Тариф/бюджет: назва тарифу CRM або орієнтир «грн/день» (звіряємо з `nutrition:tariffs`)
16. На скільки днів меню: 5 (будні) / 6 / 7
17. Дата старту (для сезонності — опційно)
18. Коментар менеджера (все, що не влізло вище)

## Мінімально необхідне для генерації

- калораж (заданий або розрахований з блоку 1)
- алергії/виключення (навіть якщо «немає» — явно підтверджені)
- кількість прийомів їжі
- тариф або бюджет
- кількість днів

Все інше — покращує якість, але не блокує.
